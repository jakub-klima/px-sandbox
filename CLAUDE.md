# Pokyny pro Claude

## Git workflow
- Změny commitni a rovnou pushni do větve `main`.
- Na push do `main` se uživatele neptej, nečekej na vyzvání.

## Aplikace
- Jednotlivé appky jsou na sobě zcela nezávislé.
- Nedrž se mezi nimi žádných společných konvencí, stylu, struktury ani sdíleného kódu.
- Novou appku přidej zcela nezávisle na těch stávajících.
- Jediný společný rys: jsou to webové aplikace v HTML + CSS + JavaScriptu.
